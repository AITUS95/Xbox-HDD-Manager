# Xbox HDD Manager 1.0.1

Source release for Linux with Python 3.10-compatible tests. Includes the English GTK interface, QCOW2/RAW image selection, FATX mounting, verified backups, busy-partition recovery, bundled FATX driver source, and installation scripts.

The release archive is source-based and builds the driver on the target system. Ubuntu and Debian dependency commands are in the README; other Linux distributions require equivalent packages. The graphical interface and actual FUSE/NBD lifecycle should be tested on the target system before relying on the application for important data.
